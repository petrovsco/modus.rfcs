# CLAUDE.md

## House rules

The rules in [`.claude/rules/modus/`](.claude/rules/modus/) are loaded automatically
wherever this repo is checked out — a cloud session, a collaborator's machine, a
machine with no modus installed. They are managed by modus: edit a rule in the
modus repo, not here.

## What this repo is

The specifications for **petrovsco/modus**, the plugin marketplace whose own
`plugins/modus/rules/rfc-convention.md` defines the convention this repo
follows. Changing the convention and changing these files is the same session's
work twice over: the rule is the product, this repo is the proof it is usable.

The code repo holds the plugins, the configs and the tools. Nothing about what
we intend to build next is committed there.
